# レビューフィードバック適用スキル

## 概要

レビュワーからのフィードバックを受け取り、以下の3段階で処理する:

1. `docs/` 配下の既存仕様書への影響調査・修正
2. `.cursor/skills/excel-to-md/SKILL.md` のルール更新
3. `.cursor/skills/excel-to-md/reference.md` のテンプレート更新（該当する場合）

---

## 実行手順

### Step 1: フィードバック解析

ユーザーから提示されたフィードバックテキストを解析し、以下を特定する:

- **変更ルール**: 何をどう変えるべきか（命名規則・記載フォーマット・表現統一など）
- **検索パターン**: 該当箇所を探すための grep キーワード
- **影響スコープ**: 特定セクションか、全体に渡るか

### Step 2: 影響範囲調査

```bash
# docs/ 配下の全 .md ファイルを対象に検索パターンで走査
rg "<検索パターン>" docs/ --type md
```

検索結果から:
1. 対象ファイル一覧を作成
2. 各ファイルの該当箇所（行番号・現在の記載内容）を列挙
3. **ユーザーに修正計画を提示し、承認を得る**

### Step 3: 仕様書修正

承認後、以下の手順で修正:

1. 対象ファイルを1つずつ修正
2. 修正前→修正後の対比が分かるようにする
3. 全ファイル完了後、修正サマリをユーザーに報告

### Step 4: excel-to-md スキル更新

フィードバックのルールを恒久化するため、以下のファイルを更新:

#### 4a. SKILL.md（`.cursor/skills/excel-to-md/SKILL.md`）

追記先の判断基準:
- **表記・判断ルール** → 「判断基準」セクション末尾に追加
- **出力構造・テンプレート変更** → 「Step 4: MD仕様書の構成」内の該当章に追加
- **解析手順の変更** → 該当 Step に追加

#### 4b. reference.md（`.cursor/skills/excel-to-md/reference.md`）

追記先の判断基準:
- **テーブルのカラム変更・フォーマット変更** → 該当セクションのテンプレートを更新
- **新しい凡例・注記** → 該当セクション内に追加
- **セクション構造の変更** → 目次とテンプレート本体の両方を更新

#### 追記時のルール

- 既存ルールと矛盾する場合は、既存ルールを置換する（追記ではなく上書き）
- 新ルールの記載位置は、関連する既存ルールの直後に配置する
- SKILL.md は 500行以内を維持する

### Step 5: 完了報告

以下をユーザーに報告:

| 項目 | 内容 |
|---|---|
| 修正した仕様書 | ファイル名と修正箇所数 |
| SKILL.md の変更 | 追加/変更したルールの要約 |
| reference.md の変更 | 更新したテンプレート箇所（該当する場合） |

---

## 判断基準

- フィードバックが「特定ファイルのみ」への指摘か「全体ルール」かを区別する
  - 特定ファイルへの指摘でも、他ファイルに同様の問題がないか確認する
  - 再発可能性がある場合は Step 4 でスキルを更新する
- 既存ルールと矛盾するフィードバックの場合、ユーザーに確認してから進める
- フィードバックが曖昧な場合は、具体例を含めてユーザーに解釈を確認する
