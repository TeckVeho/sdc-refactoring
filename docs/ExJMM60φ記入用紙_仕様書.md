# ExJMM60φ記入用紙 仕様書

> **対象ファイル**: ExJMM60φ記入用紙.xltm
> **ファイル種別**: .xltm（マクロ付きテンプレート）
> **用途**: １号機で照射する60φPE丸棒の線量測定記録・計算・報告書発行を行うテンプレート。受付番号入力後にDBから在庫情報を取得し、ABS値から線量を多項式計算して記録・保存する。
> **VBA プロジェクト**: モジュール 14 本（.bas 8 / .cls 4 / .frm 1）
> **外部連携**: DSN=ricdb（Oracle）、UID=ric / PWD=t6101
> **解析日**: 2026-06-29（excel-to-md スキルによる自動解析）

### 2.2 シート「測定値」

**用途**: 線量測定データの入力・計算を行うメインシート。最大90バッチ（6本×30回照射×上中下3段）の測定値を記録する。

**レイアウト概要**:

| 行範囲 | 列範囲 | 内容 |
|---|---|---|
| 1 | E1 | タイトル: 「１号機線量測定記録（６０φPE丸棒用）」 |
| 1 | N1–O1 | 記録先フォルダパス（`D:\JMM線量\`） |
| 2 | B2–J2 | ヘッダ: 受付番号/受付本数/指定線量/測定器/線量計種類/計算式コード/下限/上限/前回記録 |
| 2 | N2–O2 | 小数点以下桁数設定（初期値: 1） |
| 3 | B3–K3 | 入力行（`UkeHed` 範囲） |
| 4 | A4–K4 | データヘッダ: バッチ/照射月日/照射時間/測定温度/RIC-No/線量計番号/厚さ/ABS/測定線量/備考/計算式コード |
| 5–544 | A–K | 測定データ領域（`DataTB` 範囲: G5:K544）。18行×30バッチ繰返し（各バッチ: 6本×3段＝18行） |
| 5–10 | Q–AD | DB から取得した参照データ領域（線量計種類/有効計算式コード/計算式パラメータ） |
| 4 | N4–O4 | 会社コード（固定: `0725`） |

**繰返し構造（行5以降）**:

各バッチは18行で構成:
- 6行 × 下段 → 6行 × 中段 → 6行 × 上段
- 各行: バッチ番号 / 照射月日 / 照射時間 / 測定温度 / RIC-No / 線量計番号 / 厚さ / ABS / 測定線量 / 備考 / 計算式コード

**レイアウト概要**:

| 行範囲 | 内容 |
|---|---|

| 4–5 | 受付番号表示 / 線量計添付位置の注記 |

| 19–28 | バッチ2 |
| … | 以降同構造で繰返し（最大30バッチ分 = 行160まで） |

各バッチブロック構成:
- バッチ番号 → 照射日 → 照射時間 → RIC-No → 下段線量(A-0/A-1/B-0/B-1/C-0/C-1) → 中段線量 → 上段線量 → MIN → MAX

### 6.8 線量計算.bas

| プロシージャ | 処理内容 |
|---|---|
| `線量(myR, myC)` | ① 照射日/照射時間/測定温度/厚さの未入力チェック ② ABS/厚さ比（`myAbsT`）を算出 ③ `SikiPara` から有効式の多項式係数で温度別線量を計算（最大3式） ④ 温度補正係数を計算 ⑤ 有効式数に応じた線形内挿で最終線量決定 ⑥ 誤差修正式による補正 ⑦ 線量×温度補正係数を `HyoujiKeta` 桁でRoundDownしてセルに書込 |

**計算ロジック詳細**:
- 多項式: `Dose = E + D×t + C×t² + B×t³ + A×t⁴`（t = ABS/厚さ）
- 温度補正: `OndHose = E + D×T + C×T² + B×T³ + A×T⁴`（T = 測定温度）
- 有効式数=2の場合: 温度区間による線形内挿
- 有効式数=3の場合: 3区間の線形内挿
- 最終線量 = `RoundDown(線量 × OndHose, HyoujiKeta)`

## 10. セキュリティ注意事項

| # | カテゴリ | 内容 | リスク |
|---|---|---|---|
| 1 | DB認証情報 | `SQL_Execution.bas` に DSN/UID/PWD がハードコード（`DSN=ricdb;UID=ric;PWD=t6101`） | 資格情報漏洩 |
| 2 | シート保護 | パスワード `ijiruna` が「使用方法」シートに平文で記載 | 保護無効化 |
| 3 | ファイルI/O | `MkDir` / `Open For Output` でファイルシステムに直接書込み | パス改ざん時の任意書込み |
| 4 | SQL構築 | 文字列連結によるSQL構築（パラメータ化されていない） | SQLインジェクションの可能性 |
| 5 | エラー処理 | `On Error Resume Next` が多用され、一部でエラーが握りつぶされる | サイレント障害 |
| 6 | VBA Stomping | olevba検出: VBAソースコードとP-codeが異なる可能性の警告あり | 隠しコードの存在可能性（false positive の可能性あり） |
