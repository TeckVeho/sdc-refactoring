### 6.10 計算コード.bas

**`有効計算式コード()`**:

```sql
SELECT keisask FROM keicode WHERE yflg1='1' AND SUBSTR(keisask,2,1)='1' ORDER BY keisask
```

- 有効な計算式コードを DB から取得し、`KeiCode` 範囲に展開。取得後に `KeiCode` の名前付き範囲を再定義。

**`計算パラメータ()`**:

- `keicord` に入力された計算式コードが前回と異なる場合、DB `keicode` テーブルから以下を取得:
  - 式1〜3: 5次多項式係数（E,D,C,B,A）＋校正温度＋有効フラグ
  - 温度補正式: 5次多項式係数＋有効フラグ
  - 誤差修正式: 5次多項式係数＋有効フラグ
- 取得した係数を `SikiPara` 範囲に展開し、有効/無効降順・温度昇順でソート。

### 6.12 線量計算.bas

**`線量(myR, myC)`**: ABS 値と厚さから線量を算出する中核ロジック。

1. バッチ先頭行を `Int((myR - 5) / 12) * 12 + 5` で算出
2. 照射日・照射時間・測定温度・厚さの必須チェック
3. ABS/厚さ比（`myAbsT`）を算出
4. `SikiPara` から有効な計算式（最大3式）の係数を読み取り、5次多項式で各式の線量を算出:
   - `Dose(j) = Σ(係数(i) × myAbsT^i)` （i=0〜4）
5. 有効式数に応じた温度補間:
   - 1式: そのまま採用
   - 2式: 温度による線形補間
   - 3式: 温度区間ごとの線形補間
6. 温度補正係数の算出（5次多項式）
7. 誤差修正式の適用（有効な場合）
8. 最終線量 = `Round(線量, 4) × 温度補正係数` を `RoundDown` して `HyoujiKeta` 桁で表示
9. 使用した計算式コードを K 列に記録

## 10. セキュリティ注意事項

olevba 解析結果:

| 種別 | キーワード | 内容 |
|---|---|---|
| AutoExec | `Workbook_Open` | ファイルを開くと自動実行（`初期化()` → DB接続・StartForm表示） |
| AutoExec | `Workbook_BeforeClose` | ファイルを閉じると自動実行（保存確認ダイアログ） |
| AutoExec | `CommandButton1_Click` | ActiveX コントロールのイベント（在庫DB照会） |
| AutoExec | `Worksheet_Change` | セル変更時に自動実行（線量計算） |
| Suspicious | `Open` | ファイルを開く可能性あり（`Workbooks.Open`、テキストファイル出力） |
| Suspicious | `Write` | ファイルへの書込み（`Write #` でテキストファイル出力） |
| Suspicious | `Output` | ファイルへの書込み（`Open ... For Output`） |
| Suspicious | `MkDir` | ディレクトリ作成（年度フォルダの自動作成） |
| Suspicious | `ActiveWorkbook.SaveAs` | ブックの保存（xlsm 形式で保存） |
| Suspicious | `Chr` | 文字列操作（改行 `Chr(13)` のみ、難読化目的ではない） |
| Hex String | `zGfd` | `7A476664`（olevba による誤検出、実害なし） |

> **注意**: DB 接続文字列（`DSN=ricdb;UID=ric;PWD=t6101`）が **SQL_Execution.bas** に平文で埋め込まれています。外部共有時はマスキング・権限分離を推奨します。

> **シート保護パスワード**: `ijiruna`（「使用方法 」シートに平文記載あり）
