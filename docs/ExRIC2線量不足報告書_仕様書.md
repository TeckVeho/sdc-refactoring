# ExRIC2線量不足報告書 仕様書

> **対象ファイル**: ExRIC2線量不足報告書.xlsm
> **ファイル種別**: .xlsm（マクロ付き）
> **用途**: ２号機（RIC2）の線量不足報告書（工程確認・追加照射指示書）を自動生成する。照射管理システム（Oracle DB）から線量不足データを抽出し、追加照射パス数の計算・印刷までを支援する。
> **VBA プロジェクト**: モジュール 10 本（.bas 4 / .cls 5 / .frm 0）
> **外部連携**: DSN=ricdb（Oracle）、UID=ric
> **解析日**: 2026-06-29（excel-to-md スキルによる自動解析）

- 1パスあたり線量 = `SokutSN` / `JituP`（測定線量÷実パス数）

- 追加パス数 = `ROUNDUP((不足線量 / 1パスあたり線量) / 2, 0) * 2`（偶数に切上げ）
