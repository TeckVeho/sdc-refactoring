# ExRIC3線量不足報告書住電用 仕様書

> **対象ファイル**: ExRIC3線量不足報告書住電用.xlsm
> **ファイル種別**: .xlsm（マクロ付き）
> **用途**: ３号機（RIC3）の線量不足報告書（住友電工専用）を作成する。照射管理番号を選択すると、DBから測定データ・照射計画データを抽出し、追加照射のパス数を自動計算して帳票を印刷する
> **VBA プロジェクト**: モジュール 10 本（.bas 5 / .cls 5 / .frm 0）
> **外部連携**: DSN=ricdb（Oracle）、DB接続先 IP: DSN 経由
> **解析日**: 2026-06-29（excel-to-md スキルによる自動解析）

## 10. セキュリティ注意事項

| No | 区分 | 内容 | リスク |
|---|---|---|---|
| 1 | 認証情報のハードコード | `Open_oraconDB()` に DSN=`ricdb`, UID=`ric`, PWD=`t6101` が平文で記述されている | VBA コードを閲覧できるユーザーは DB 認証情報を取得可能 |
| 2 | SQL インジェクション | `線量不足線量計()` 等で `Range("SenkNo")` の値を文字列連結で SQL に埋め込んでいる | ドロップダウン入力規則により入力値は制限されているが、VBA から直接値を設定された場合にリスクあり ※推論 |
| 3 | エラー処理 | `SQL_Exe()` でエラー発生時に `End` で強制終了するため、DB コネクションが適切にクローズされない可能性がある | コネクションリークのリスク |
| 4 | シート保護 | `UserInterfaceOnly:=True` により UI 経由の編集は制限されるが、VBA からは自由にアクセス可能 | マクロ有効環境では保護が機能しない |
| 5 | On Error Resume Next | `Open_oraconDB()` で `On Error Resume Next` を使用しており、接続失敗時にエラーが無視される | 接続失敗を検知できず後続処理でランタイムエラーが発生する可能性 |
| 6 | ネットワークパス保存 | `ブック保存()` で DB から取得したネットワークパスに SaveAs する | パス情報の改ざんにより意図しない場所にファイルが保存される可能性 ※推論 |
