| `P16` | `=IF(N16="","",L16*E16/40)` | 箱係数の計算 | ✓ |
| `Q16` | `=IF(N16="","",IF(M16="移動照射",O16/$J$7*20,N16*O16*P16))` | 標準ケース換算値の計算 | ✓ |

> M16〜Q16 は `Siki` 範囲に定義され、VBA により行18以降にコピーされる計算式テンプレート

#### `集計実行()` — Sub（ボタン起動）

- **トリガー**: 「集計」シートの「集計実行」ボタン
- **処理**:
  1. 確認ダイアログ「1,2,3号機の実績と入荷数を集計しますか？」→ No で終了
  2. `実績在庫抽出()` を呼び出し
  3. エラー時は `mpErrDes` を MsgBox 表示して終了
  4. `入荷数合計()` を呼び出し
  5. 完了メッセージ「集計終わりました」

#### `入荷数合計()` — Sub

- **処理**: 1〜3号機の入荷数量を集計
  1. `Nenn` + `Tuki` から受付番号範囲を生成（例: `20260100000` 〜 `20260199999`）
  2. 装置番号（1〜3）ごとにループ
  3. `zaiko` テーブルから `SUM(nyukasu)` を取得
  4. `rich.zaikor` テーブルからも `SUM(nyukasu)` を取得
  5. 合計を `Ric1IRI` / `Ric2IRI` / `Ric3IRI` に書込み
- **SQL**:
  - `SELECT SUM(nyukasu) FROM zaiko WHERE uno>'...' AND uno<='...' AND syouso='...'`
  - `SELECT SUM(nyukasu) FROM rich.zaikor WHERE uno>'...' AND uno<='...' AND syouso='...'`

#### `実績在庫抽出()` — Sub

- **処理**: 1〜3号機の照射実績をDBから抽出
  1. **再集計チェック**: `Ric2T` / `Ric2HT` / `Ric3T` > 0 なら確認ダイアログ
  2. **箱寸法チェック**: `Sunnpou` > 0 なら確認ダイアログ
  3. **入力チェック**: `Nenn`, `Tuki`, `Rate`, `Sokudo`, `Senngenn` が未入力ならエラー
  4. `Sheetcls()` で画面クリア
  5. **1号機実績抽出**:
     - 接続: `DSN=ricdb;UID=ric;PWD=t6101`
     - テーブル: `RIC.SYOUJ1`, `RIC.ZAIKO`, `RIC.EXKEIKAKUX`（現行）+ `rich.SYOUJR1@RICDB`, `rich.ZAIKOR@RICDB`（履歴）を UNION
     - `抽出SUB()` でシートに書込み → `SortRic1()` でソート → `Siki` 計算式をコピー → `箱寸法読込()` で箱寸法取得
  6. **2号機実績抽出**:
     - テーブル: `SYOUJ2`, `ZAIKO`（`syouso='2'`）+ `rich.SYOUJR2`, `rich.ZAIKOR`（履歴）
     - `抽出SUB()` でシートに書込み
  7. **3号機実績抽出**:
     - テーブル: `SYOUJ2`, `ZAIKO`（`syouso='3'`）+ `rich.SYOUJR2`, `rich.ZAIKOR`（履歴）
     - `抽出SUB()` でシートに書込み
  8. `SortRic2()`, `SortRic3()` でソート・合計計算
  9. 「集計」シートに戻る

#### `抽出SUB()` — Sub

- **引数**: `myDB`（接続文字列）, `strSQL`, `mySH`（シート名）, `myROW`（開始行）, `myColumn`（開始列）, `myF`（ヘッダー出力フラグ: 1=あり/0=なし）
- **処理**: ローカルに ADODB.Connection を生成し、SQL実行→シートに CopyFromRecordset で書込み
- **エラー処理**: `On Error GoTo Err_Han` → MsgBox 表示

#### `印刷範囲設定()` — Sub

- **処理**: 「1号機実績」のデータ行数に応じて PrintArea を動的設定
- **呼び出し元**: 直接呼び出し元なし（手動実行想定）

#### `SortRic1()` — Sub

- **処理**: 「1号機実績」の `JissekiHyouji` 範囲を会社コード→製品コード→受付番号の順でソート。ソート後に `罫線と書式()` を呼び出す
- **呼び出し元**: `実績在庫抽出()`

#### `SortRic2()` — Sub

- **処理**:
  1. 「2号機実績」をソート（会社コード→製品コード）
  2. W列に混載考慮計算式を設定: `=IF(AND(RC[-20]=R[1]C[-20],RC[-19]=R[1]C[-19]),0,RC[-1])`（同一会社・同一製品の重複を除外）
  3. V列合計（単純合計）を `Ric2T` に書込み
  4. W列合計（混載考慮合計）を `Ric2HT` に書込み
- **呼び出し元**: `実績在庫抽出()`

#### `SortRic3()` — Sub

- **処理**: `SortRic2()` と同一ロジックで3号機を処理。結果は `Ric3T` / `Ric3PT` に書込み
- **呼び出し元**: `実績在庫抽出()`

```sql

  AND (sy.UNO > '{UUno1}' AND sy.UNO < '{UUno2}')
  AND (sy.KMMDD > '{KKmd1}' AND sy.KMMDD < '{KKmd2}')
  AND ke.uno(+) = za.uno
UNION
SELECT sy.UNO, za.KAISYACD, za.SEHNCD, za.KAINAME, sy.SURYOU, sy.SITEISN,
       sy.KMMDD, sy.SYOITI, sy.SYOZI, sy.HANTENJ, '', ke.NAGASA
```

## 10. セキュリティ注意事項

| # | 区分 | 内容 | 対象箇所 |
|---|---|---|---|
| 1 | 認証情報ハードコード | DB接続パスワード `t6101` がソースコードに平文で記載されている | **SQL_Execution.bas** `Open_oraconDB()`, **データ抽出.bas** `実績在庫抽出()`, `抽出SUB()` |
| 2 | 複数認証情報 | UID=`ric` と UID=`rich` の2つのDB認証情報が平文で存在 | **データ抽出.bas** |
| 3 | SQLインジェクション | セルの値（会社コード・製品コード）を文字列連結でSQL文に組み込んでおり、SQLインジェクションのリスクがある | **箱寸法Ric1.bas** `箱寸法読込()`, **データ抽出.bas** `入荷数合計()` |
| 4 | シート保護の限界 | `UserInterfaceOnly:=True` はユーザー操作のみ制限し、VBA からの変更は許可する。パスワードなしのため保護解除は容易 | **画面クリア.bas** `初期化()` |
| 5 | エラー抑制 | `On Error Resume Next` による広範なエラー抑制が複数箇所にあり、DB接続エラーや SQL 実行エラーが見逃される可能性がある | **SQL_Execution.bas** `Open_oraconDB()`, `SQL_Exe()` |
| 6 | 汎用 INSERT/UPDATE/DELETE | **SQL_Execution.bas** に任意テーブルへの書込み・削除が可能な汎用関数が含まれている。本ブックでは未使用だが、マクロ経由で呼び出される可能性がある | **SQL_Execution.bas** `SQL_INSERT_UPDATE()`, `SQL_Delete()` |
| 7 | VBA Stomping 検出 | olevba による解析で VBA Stomping（ソースコードと P-code の不一致）が検出された。意図的な改変の可能性は低いが要確認 | xl/vbaProject.bin |
