# Ex月末在庫集計 仕様書

> **対象ファイル**: Ex月末在庫集計.xlsm
> **ファイル種別**: .xlsm（マクロ付き）
> **用途**: 月末時点のガンマ照射課・EB照射課・LOCA課の製品在庫および仕掛品在庫をDBから抽出し、装置別集計表を作成する。単価・単位・備考のDB記録更新機能を持つ
> **VBA プロジェクト**: モジュール 18 本（.bas 10 / .cls 8 / .frm 0）
> **外部連携**: DSN=ricdb（Oracle）、DB接続先 IP: DSN 経由
> **解析日**: 2026-06-29（excel-to-md スキルによる自動解析）

### 8.3 SQL 一覧

#### 8.3.1 γ在庫抽出（`在庫抽出()` / **抽出条件設定.bas**）

```sql
SELECT za.uno, za.kaisyacd, za.kainame, za.sehncd, se.seiname, za.siteisn*1,
       za.syouso*1, za.nyukasu*1, za.misyousu*1, za.syousu*1, za.syukasu*1,
       za.syouzusu-za.syukasu, za.pass*1, za.incnt*1, '', e.tanka,
       TRIM(e.tani), '', e.keijyou, '', e.tanka, TRIM(e.tani), e.keijyou
FROM zaiko za, sehmst se, ExSeihinZ e
WHERE (za.kaisyacd = se.kaisyacd AND za.sehncd = se.sehncd)
  AND (za.syouzusu-za.syukasu) > 0
  AND e.kaisyacd(+) = za.kaisyacd AND e.sehncd(+) = za.sehncd
ORDER BY za.kaisyacd, za.sehncd
```

#### 8.3.2 1号機仕掛品抽出（`RIC1仕掛品抽出()` / **抽出条件設定.bas**）

```sql
SELECT sj.uno, za.kaisyacd, za.kainame, za.sehncd, se.seiname, za.siteisn*1,
       za.syouso, sj.syosuu*1, sj.syoichi, sj.syotime*1, sj.ktimer*1,
       sj.ctimer, sj.syostat, '', '', e.tanka, e.tani, '', e.keijyou, '',
       e.tanka, TRIM(e.tani), e.keijyou
FROM syouk1 sj, zaiko za, sehmst se, ExSeihinZ e
WHERE sj.uno = za.uno
  AND (za.kaisyacd = se.kaisyacd AND za.sehncd = se.sehncd)
  AND sj.syokind <> '2'
  AND e.kaisyacd(+) = za.kaisyacd AND e.sehncd(+) = za.sehncd
ORDER BY za.kaisyacd, za.sehncd
```

#### 8.3.3 23号機仕掛品抽出（`RIC23仕掛品抽出()` / **抽出条件設定.bas**）

```sql
SELECT sj.uno, za.kaisyacd, za.kainame, za.sehncd, se.seiname, za.siteisn*1,
       sj.syouso*1, sj.suryou*1, za.incnt*1, sj.pass*1, sj.jituno*1, '',
       e.tanka, TRIM(e.tani), '', e.keijyou, e.tanka, e.tani, e.keijyou
FROM syouj2 sj, zaiko za, sehmst se, ExSeihinZ e
WHERE sj.uno = za.uno
  AND (za.kaisyacd = se.kaisyacd AND za.sehncd = se.sehncd)
  AND sj.smmdd*1 = 0 AND sj.jituno*1 <= sj.pass
  AND sj.dattktime*1 = 0 AND sj.jituno*1 > 0
  AND e.kaisyacd(+) = za.kaisyacd AND e.sehncd(+) = za.sehncd
ORDER BY za.kaisyacd, za.sehncd
```

#### 8.3.4 EB在庫抽出（`EB在庫抽出()` / **抽出条件設定.bas**）

```sql
SELECT za.uno, za.kaisyacd, za.kainame, za.sehncd, se.seiname, za.siteisn*1,
       za.nyukasu*1, za.syukasu*1, za.syuhnsu*1, za.incnt*1, '',
       e.tanka, TRIM(e.tani), '', e.keijyou, e.tanka, TRIM(e.tani), e.keijyou
FROM zaiko_v za, sehmst se, ExSeihinZ e
WHERE (za.kaisyacd = se.kaisyacd AND za.sehncd = se.sehncd)
  AND za.syuhnsu*1 > 0 AND za.syouso = 4
  AND za.nyukasu*1 > za.syukasu*1
  AND e.kaisyacd(+) = za.kaisyacd AND e.sehncd(+) = za.sehncd
ORDER BY za.kaisyacd, za.sehncd
```

#### 8.3.5 記録不要会社 SELECT（`表示不可会社製品()` / **記録不可コード.bas**）

#### 8.3.7 単価 INSERT/UPDATE（`単価更新()` / **製品単価更新.bas**）

```sql
-- 存在チェック
SELECT COUNT(*) FROM ExSeihinZ WHERE kaisyacd='XXXX' AND sehncd='XXX'

-- 新規（0件時）
INSERT INTO ExSeihinZ (kaisyacd, sehncd, tanka, tani, keijyou, toudate, touname)
VALUES ('XXXX', 'XXX', 9999, '単位', '備考', '日付', '作成者 在庫')

-- 更新（1件以上時）
UPDATE ExSeihinZ SET kaisyacd='XXXX', sehncd='XXX', tanka=9999,
       tani='単位', keijyou='備考', toudate='日付', touname='作成者 在庫'
WHERE kaisyacd='XXXX' AND sehncd='XXX'
```

#### 8.3.8 記録不可会社製品 INSERT/UPDATE（`記録不可会社製品()` / **記録不可コード.bas**）

```sql
-- 会社コード単位の記録不要マスタ（SEHNCD='---' が会社指定の目印）
-- 存在チェック
SELECT COUNT(*) FROM EXSEIHINZ WHERE KAISYACD='XXXX' AND SEHNCD='---'

-- 新規（0件時）
INSERT INTO EXSEIHINZ (KAISYACD, SEHNCD, KEIJYOU, TOUDATE, TOUNAME, TANI)
VALUES ('XXXX', '---', '会社名', '日付', '作成者', '有効')

-- 更新（1件以上時）
UPDATE EXSEIHINZ SET KAISYACD='XXXX', SEHNCD='---', KEIJYOU='会社名',
       TOUDATE='日付', TOUNAME='作成者', TANI='有効'
WHERE KAISYACD='XXXX' AND SEHNCD='---'

-- 製品コード単位の記録不要マスタ（KAISYACD='----' が製品指定の目印）
-- 存在チェック
SELECT COUNT(*) FROM EXSEIHINZ WHERE KAISYACD='----' AND SEHNCD='XXX'

-- 新規（0件時）
INSERT INTO EXSEIHINZ (KAISYACD, SEHNCD, KEIJYOU, TOUDATE, TOUNAME, TANI)
VALUES ('----', 'XXX', '製品名', '日付', '作成者', '有効')

-- 更新（1件以上時）
UPDATE EXSEIHINZ SET KAISYACD='----', SEHNCD='XXX', KEIJYOU='製品名',
       TOUDATE='日付', TOUNAME='作成者', TANI='有効'
WHERE KAISYACD='----' AND SEHNCD='XXX'
```

> **無効化時**: 同じキーで `TANI='無効'` に UPDATE する（論理削除）。
