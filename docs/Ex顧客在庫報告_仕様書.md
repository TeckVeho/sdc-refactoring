# Ex顧客在庫報告 仕様書

> **ファイル種別**: .xlsm（マクロ付き）
> **用途**: 顧客別在庫データをDBから抽出し、報告書形式で表示・記録する
> **VBA プロジェクト**: モジュール 13 本（.bas 7 / .cls 6 / .frm 0）
> **外部連携**: DSN=ricdb（Oracle）
> **解析日**: 2026-06-29

---

### データフロー 場所マーク（9章）

9章のデータフロー（テーブル・ツリー図）では、処理が行われる場所を以下のアイコンで区別します。

| アイコン | 種別 | 意味 |
| --- | --- | --- |
| 📊 | シート操作 | ワークシート上のセル書込み・読取り・表示変更 |
| 🖥️ | 画面操作 | ユーザーフォーム（.frm）の表示・入力・操作 |
| 🗄️ | DB操作 | Oracle DB への SELECT / INSERT / UPDATE / DELETE |
| 📄 | VBA内部処理 | 変数計算・条件分岐など、画面・シートに直接関与しない処理 |

✓ は **保守時に最初に確認すべき項目** を示します。

### 6.2 **在庫抽出設定**

#### `データ抽出(mySyuF, myNyu, myKaisya, mydate)`
📊🗄️ 在庫データ抽出の中核。全報告書から共通呼出される。

| 引数 | 型 | 意味 |
| --- | --- | --- |
| mySyuF | Integer | 1=出荷日含む, 0=含まず |
| myNyu | Integer | 1=入荷日含む, 0=含まず |
| myKaisya | String | 4桁会社コード |
| mydate | String | YYYYMMDD形式日付 |

処理フロー:
1. 🗄️ `sehmst` から製品マスター取得 → `SeihinnTB` に格納
2. 🗄️ `zaiko` から在庫データ取得 → `Zaiko` に格納
3. 🗄️ `tokumst` から会社名取得 → `KaiName` に格納
4. 🗄️ `zaikor` から在庫履歴取得 → `ZaikoR` に格納
5. 🗄️ `syukar` から出荷履歴（加算分）取得 → `SyukkaZ` に格納
6. 🗄️ `syukar` から出荷履歴（減算分）取得 → `SyukkaR` に格納

接続文字列:
- 在庫系: `DSN=ricdb;UID=ric;PWD=t6101`
- 履歴系: `DSN=ricdb;UID=rich;PWD=t6101`

#### `データ抽出サブ(myDB, strSql, mySH, myRow, myColumn, myF)`
📄🗄️ ADO経由の汎用DB抽出。

| 引数 | 型 | 意味 |
| --- | --- | --- |
| myDB | String | 接続文字列 |
| strSql | String | SQL文 |
| mySH | String | 出力シート名 |
| myRow | Single | 出力開始行 |
| myColumn | Single | 出力開始列 |
| myF | Integer | 1=ヘッダ出力あり, 0=なし |

処理:
1. ADODB.Connection で接続
2. Execute でレコードセット取得
3. `CopyFromRecordset` でシートに一括貼付
4. エラー時はメッセージ表示して終了

## 10. セキュリティ注意事項


| No | カテゴリ | 内容 | リスク |
| --- | --- | --- | --- |
| 1 | 認証情報ハードコード | ODBC 接続文字列に UID/PWD がハードコード（`ric`/`t6101`, `rich`/`t6101`） | 中：VBAエディタで閲覧可能 |
| 2 | SQLインジェクション | ユーザー入力（会社コード・日付）を文字列結合でSQL生成 | 中：文字列連結によるSQL構築 |
| 3 | UNCパス | 保存先がネットワーク共有フォルダー | 中：ネットワーク障害時にエラー発生。アクセス権管理が必要 |
| 4 | 保存時上書き | SaveAs時に同名ファイルがあると確認なしで上書き | 中：既存報告書が消失する可能性 |
| 5 | 保存なし終了 | Close 時に Alerts 無効化 | 低：変更破棄が無警告 |

- 条件付き書式、グラフ・画像、印刷設定
