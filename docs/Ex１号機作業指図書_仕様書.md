# Ex１号機作業指図書 仕様書

> **対象ファイル**: `xlms/Ex１号機作業指図書.xlsm`
> **種別**: Excel マクロ有効ブック (.xlsm)

> **用途**: 1号機照射作業指図書の作成・印刷・照射時間計算・DB登録

### 2.1 「指図書」シート（codeName: Sheet1）

**概要**: 1号機作業指図書のメインフォーム。照射条件の入力、セット方法の選択、照射時間の算出結果表示、印刷を行う。

**レイアウト構造** (58行 × 27列 = A〜AA):

| 行範囲 | 領域 | 内容 |
|---|---|---|
| R2 | ヘッダ左 | 文書番号 `="G１－２5（"&MAX(改訂履歴!A6:A105)&")"` |
| R3 | タイトル | 「１ 号 機 作 業 指 図 書（製 品 仕 様 書 な し）自動印字用BCR読み出し」 |
| R3 | 確認者・作成者 | S3=確認者, V3=作成者（社員名+作成日を改行結合） |
| R4 | 受付番号 | E4=受付番号（バーコード入力対応） |
| R5 | 顧客名 | E5=顧客名（DB 自動取得） |
| R7 | 項目ヘッダ | No. / 項目 / 指図内容 / 確認者チェック |
| R8-9 | ① 開始日確認 | 照射開始期間 N8〜Q8、期間終了 S8〜U8 |
| R10 | ② 製品寸法 | 幅 J10 × 長さ N10 × 高さ R10（cm） |
| R11 | 重量 | J11=重量（kg） |
| R13-37 | ③ セット方法 | セット位置（6方位）、セット図、セット数 P19、受付数 U19、保護板距離 J21、箱寸法（幅 L30 / 長さ P28 / 高さ S26）、台高さ N34 |
| R38-42 | ④ 照射時間・線量率 | セット方法選択（■□）、線量率 R38、時間 U38、シート計算、係数 S39、線量率測定 R41/U41、線量計種類（RadixW/AE-132a） |
| R44-45 | ⑤ 反転回転 | 回転回数 J44、方法（上下/左右/その他） |
| R47-51 | ⑥ 照射時線量計貼付 | 有無、貼付位置、指定線量 N48、上限 N49、下限 S49、線量計種類 |
| R53 | ⑦ 照射管理ラベル | 有無、貼付位置 M53、CI有無 |
| R55 | ⑧ その他（温度管理等） | 有無、内容 K55 |
| R57 | ⑨ 顧客先の指示書等 | 有無 |
| R59 | 備考 | B59=Bikou, C59=Bikou2 |
| AA3-5 | 隠し計算列 | 月初日 AA3、月末日 AA4、入荷日 AA5 |

**■□チェックボックス動作**:
右クリックまたはセル変更で■⇔□をトグルする。対象セル:
- I38（セット方法）、I39（シート計算）、I40（その他）、I41（線量率測定）
- P42 / T42（RadixW / AE-132a：線量率測定用）
- K45 / O45 / S45（上下 / 左右 / その他反転）
- I47 / O47 / S47（線量計有 / 最下部中央 / その他）
- O50 / S50（RadixW / AE-132a：照射時線量計）
- I51（線量計無）
- I53 / P53 / R53 / U53（管理ラベル有 / CI有 / CI無 / ラベル無）
- I55 / Q55（温度管理有 / 無）
- I57 / L57（顧客指示有 / 無）

**Shape（図形）制御**:
- 「グループ化 14」: 箱セット図
- 「グループ化 18」: シートセット図
- 「直線コネクタ 88」: 未選択時の表示線
- 「直線矢印コネクタ 10」: 1号機セット方法矢印
- 「直線矢印コネクタ 106」: シート計算矢印
- 「直線矢印コネクタ 108」: 線量率測定矢印

**レイアウト構造** (50行 × 18列):

| 行範囲 | 内容 |
|---|---|
| R1 | 注記「セル色が青は式が入っている」 |
| R2-3 | 列ヘッダ（開始日 / 選択リスト / 台高さ / 製品高さ範囲 / DB線量率 / チェック集計 K-R列） |
| R4-8 | 高さ別線量率パラメータ（60cm/50cm/40cm/30cm/20cm未満） |
| R9 | シート照射時間（2cm以下） |
| R11 | 保護板距離基準値、箱寸法最小値、重量最小値、SPKフォルダパス |
| R15 | 列番号・行番号（計算用） |
| R19 | 変更日判定（Hennkou） |
| R20-50 | RateTBL: DB から読み込んだ線量率テーブルデータ保持領域 |

**チェック集計数式** (K3〜R3):
- K3: セット方法選択数（SetSentaku）
- L3: 反転方法選択数（Hanten）
- M3: 線量計有無（SenKei）
- N3: 線量計貼付位置（SenIti）
- O3: 貼付線量計種類（SenSyu）
- P3: 管理ラベル有無（Label）
- Q3: CI貼付有無（CIumu）
- R3: 顧客指示有無（KokyakuSiji）

- 読み込んだ値を設定値シートの G4〜G9（DoseR50〜SheetHr）に格納
- DBTourokuUMU（全値の積）が0の場合は未登録警告
- 保護板距離を 25cm に設定

#### `Syain_read()` — Sub
- InputBox で社員番号を入力
- `shainmst` テーブルから社員名を SELECT
- 未登録の場合は再入力を促す
- 取得した社員名を作成日と改行結合して「作成者」セルに設定
- DB接続文字列: `DSN=ricdb;UID=ric;PWD=t6101`

### 6.11 **チェック計算実行**（.bas）

#### `照射時間計算実行()` — Sub
- DBTourokuUMU チェック → `チェック()` → 計算実行
- SheetCal=■ なら `シート照射時間()` / それ以外は `時間計算()`
- 計算完了メッセージ表示

#### `チェック(mpEerrDes)` — Sub
- 入力項目の網羅的バリデーション（約25項目）:
  - 照射開始期間の入力有無・DB線量率との整合性
  - 作成者（未設定なら `Syain_read()` 呼出）
  - 受付番号の妥当性（"201609-8893" 以上）
  - 重量・保護板距離・箱寸法の入力有無
  - ④セット方法選択の排他性（SetSentaku=1）
  - ④線量率測定時の線量計種類（RituSenKei=1）
  - ⑤反転回数・反転方法の整合性
  - ⑥線量計有無・貼付位置・指定/上限/下限線量の妥当性
  - ⑦管理ラベル有無・貼付位置・CI有無
  - ⑧温度管理の整合性
  - ⑨顧客指示の選択

#### `時間計算(mpErrDes)` — Sub
- **1号機セット方法（SetHouhou=■）の場合**:
  - 保護板距離が基準値と一致するかチェック
  - 台高さを `台高さ()` 関数で算出
  - 重量5kg未満かつ高さ50cm未満 → 係数 Ceff=0.9、それ以外 → Ceff=1.0
  - 線量率 = mpDoseR / Ceff（小数第4位切り上げ）
  - 照射時間 = 指定線量 / 線量率（小数第4位切り上げ）
- **線量率測定（SetRitu=■）の場合**:
  - 測定値（SenRitu）が入力済なら照射時間 = 指定線量 / SenRitu（小数第5位切り上げ）
  - セット方法側の値は "---" 表示

#### `シート照射時間(mpErrDes)` — Sub
- SheetHr（10kGy照射時間）が0の場合はエラー
- 台高さを20cmに固定（確認ダイアログ）
- シート高さ40cm以上は計算不可
- 係数 Ceff = 1（シートの場合は常に1）
- 線量率 = 10 / SheetHr
- 照射時間 = 指定線量 / 線量率（小数第5位切り上げ）

### 6.12 **セット図表示非表示**（.bas）

#### `セット図箱表示()` — Sub
- 「グループ化 14」（箱図）= Visible、「グループ化 18」（シート図）= False
- 台高さを `台高さ()` で自動計算
- 重量<5kg かつ 高さ<50cm なら Ceff=0.9、それ以外は Ceff=1.0

#### `セット図シート表示()` — Sub

## 10. セキュリティ注意事項

### 10.1 認証情報のハードコード

| 項目 | 値 | 場所 | リスク |
|---|---|---|---|
| DSN | `ricdb` | **SQL_Execution** `Open_oraconDB()` | ODBC設定依存 |
| UID | `ric` | **SQL_Execution** `Open_oraconDB()` | DB認証情報がソースに平文記載 |
| PWD | `t6101` | **SQL_Execution** `Open_oraconDB()` / **データ取得書込み** `Syain_read()` | パスワード平文 |

> **推奨**: 接続文字列は設定シートまたは外部設定ファイルに移行し、VBA ソースから除去すること。

### 10.2 SQL インジェクション

- 全 SQL 文が文字列結合で構築されており、パラメータバインドを使用していない
- 受付番号（`mpUno`）やセル入力値が直接 SQL 文に埋め込まれている
- 攻撃リスクは低い（社内ネットワーク限定使用）が、不正入力による SQL エラーの可能性あり

### 10.3 エラー処理

- `On Error Resume Next` が多用されており、DB エラーが握りつぶされる箇所がある
- `SQL_Exe()` でエラー時に `Stop` ステートメントが残っている（デバッグ用、本番では IDE 停止の原因）
- `rs.Close` がオブジェクト解放後に呼ばれる箇所あり（エラー抑制で回避）

### 10.4 シート保護

- `UserInterfaceOnly:=True` でシート保護しているため、VBA からの書込は許可されている
- パスワード付き保護は設定されていない

### 10.5 VBA Stomping 検出

- olevba が VBA Stomping を検出しているが、P-code とソースコードの不一致はファイル保存時のバージョン差異による false positive の可能性が高い
- 悪意のあるコードは確認されていない

### 10.6 デバッグフラグ

- `指図書!A1`（Debug セル）が "*" の場合、終了処理が無効化される
- 本番運用時はこのセルが空であることを確認すること
